Instaladores do **Servidor Comercial** (Martins, Catálogo de Produtos e Reserva Hotel).

Este repositório contém só os instaladores. Os Servidores já instalados se
atualizam sozinhos a partir daqui; para uma instalação nova, baixe o
`ServidorComercial Setup X.Y.Z.exe` da [última release](../../releases/latest).
